# CrackTwinStudio — 크랙 디지털 트윈 스튜디오

드론·카메라로 촬영한 콘크리트 구조물 사진에서 **AI로 균열을 픽셀 단위 검출**하고,
포토그래메트리로 복원한 **3D 표면에 역투영**하여 실척(mm) 폭·길이를 산출한
**자체완결형 보고서(`.twin`)** 를 만들고 웹 3D 뷰어로 점검하는 프로그램입니다.

```
사진 + 카메라 파라미터(XMP) + 3D 메시(PLY)
        │
        ▼  AI 검출 → 3D 역투영 → 실척 정량화 → 다시점 융합
        │
   보고서 (.twin)  ──▶  3D 뷰어로 점검 · 검토
                   ──▶  PDF 보고서
                   ──▶  이전 검사와 비교 (신규 · 성장 추적)
```

---

## 왜 3D인가

사진 한 장에서 균열 폭을 재려면 "1픽셀이 몇 mm인가"를 알아야 합니다.
그런데 그 값은 **촬영 거리와 표면 경사에 따라 픽셀마다 다릅니다.**

이 프로그램은 픽셀에 상수를 곱하지 않습니다. 균열 픽셀마다 3D 표면으로 광선을 쏴
**그 픽셀이 실제로 덮는 크기**를 구하고, 표면 기울기(cosθ)까지 보정합니다.
같은 균열이 여러 사진에 찍히면 3D 공간에서 하나로 합쳐 **균열 1개 = 객체 1개**로 만듭니다.

## 주요 기능

| | |
|---|---|
| **AI 균열 검출** | DeepLabV3+ 기반 픽셀 단위 세그멘테이션 (FP16 타일 추론) |
| **실척 정량화** | 원근·경사 보정 스케일맵으로 mm 폭·길이 산출 |
| **다시점 융합** | 여러 사진의 같은 균열을 3D에서 하나로 병합 |
| **3D 뷰어** | 심각도 색상, 심각도·신뢰도 필터, 측정 도구, 사진 정렬 |
| **검토 워크플로** | 검사원의 확인·오탐·메모 기록 (원본 불변, 사이드카 저장) |
| **검사 간 비교** | 두 시점의 균열을 정합·매칭해 신규·성장·미검출 판정 |
| **PDF 보고서** | 표지·요약 / 위치도 / 균열 대장 / 사진 대지 |
| **재학습 데이터 축적** | 검토의 오탐 라벨이 검출 모델 재학습(파인튜닝) 데이터로 쌓임 |

전부 **오프라인 자체완결**입니다. 인터넷 연결이 필요 없습니다.

## 빠른 시작

```bash
git lfs install && git clone https://github.com/Seongwon5/CrackTwinStudio.git
```

```bash
pip install -r requirements.txt
```

```bash
python app.py
```

대시보드에서 **이미지+XMP 폴더**와 **PLY 메시**를 선택하고 분석을 시작하면
`reports/` 에 `.twin` 보고서가 생성됩니다.

>
> ```bash
> python -c "import trimesh.ray; print(trimesh.ray.has_embree)"
> ```
>
> 자세한 내용은 [사용자 매뉴얼 §2 설치](docs/USER_GUIDE.md#2-설치)를 참조하세요.

```

### `.twin` 포맷

단일 ZIP 컨테이너입니다 (원자적 쓰기로 손상 방지).

| 멤버 | 내용 |
|---|---|
| `meta.json` | 카메라 포즈 · 균열 통계 · 형상(ribbons) — 기하만 |
| `tiles/N.bin` | 계층 LOD 타일 — 뷰어가 보이는 것만 거리별 해상도로 스트리밍 (면 수 제한 없음) |
| `mesh.ply` | 타일로 만들 수 없는 PLY 일 때만 원본 메시 |
| `img/NNNN_thumb.jpg` / `_full.jpg` / `_mask.png` | 썸네일 / 원본 / 검출 마스크 |

파일 하나만 옮기면 다른 PC에서 그대로 열립니다.

## 핵심 전제와 한계

> **전제: PLY의 `1 unit = 1 m`**
> 모든 mm 측정이 이 스케일 전제에 의존합니다.

**메트릭 스케일 캘리브레이션이 최우선 과제입니다.** 알려진 실측 치수로 검증하기 전까지
mm **절대값은 신뢰할 수 없으며**, 보고서에 `scale_warning` 으로 표시됩니다.

- ✅ **이미 유효**: 균열의 상대 순위 · 형상 · 위치
- ⚠️ **검증 필요**: mm 절대값

뷰어의 [2점 캘리브레이션](docs/USER_GUIDE.md#5-8-스케일-캘리브레이션-중요)으로 보정할 수 있습니다.

그 밖의 한계:
- 뷰 간 정합 오차가 병합·융합 거리 파라미터(eps·복셀)의 한계를 결정합니다
- 검사 간 비교의 '미검출'은 보수 완료와 미관측을 구분하지 못합니다
- 구형식(v1) `.twin` 은 지원하지 않습니다 — 재분석이 필요합니다
